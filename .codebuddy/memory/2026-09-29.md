## 顺手（今日重复出现的环境经验）

- 新开的 shell 里**没有 `node`**（报「术语 'node' 不会被识别」）—— 每条命令都要先
  `Import-Module D:\usexxx\use-xxx.psm1; use-node 22.23.2`。
- 跑 `scripts/smoke-api.ps1` 前必须先杀掉手动起的服务（它自己起 wrangler dev 占 8787），跑完再拉回来。
- 杀服务时 `Get-NetTCPConnection -LocalPort 8787` 给出的只是 workerd，**父进程 pwsh/npm 也要清**，
  否则会有残留进程把 8787 又抢回去。
- `git commit --no-verify=false` 会**静默失败**（非法参数，被 `Select-String` 过滤后看着像没输出）—— 布尔开关不要带 `=值`。
